Our Classes

Classes We Offer

We offer on-site workshops, multi-week class programs, and personalized tutoring for web development and computer science, bringing our instruction directly to schools and educational centers.

Technology Literacy for Older Adults
A patient, friendly workshop series to help older adults feel comfortable and confident with modern technology — phones, email, video calls, online safety, and more.
Price: $120 / 10-week session

Scratch Jr
Scratch Jr is a kid-friendly programming language for creating interactive stories, games, and animations that fosters critical thinking, problem-solving, computational thinking, and creativity skills.
Price: $120 / 6-week session

Scratch
Scratch is a user-friendly visual programming language and platform developed by MIT that promotes creativity and problem-solving through interactive storytelling, gaming, and animations.
Price: $120 / 6-week session

Coding with Python
Build practical coding skills from the ground up in our 6‑week Python course. Learn real-world programming fundamentals, build mini‑games, and leave with working code you can show off — no prior coding experience required..
Price: $120 / 6-week session

Robotics with Mbot2
Robotics leverages the powerful Makeblock mBot2 robot to introduce students to the fundamentals of robotics, coding, and engineering. Engage in exciting projects that involve building, coding, and testing the mBot2, fostering creativity and technical skills.
Price: $150 / 6-week session

Introduction to Web Development
The Introduction to Web Development curriculum covers the basic concepts of HTML, CSS, and JavaScript, including creating a simple webpage, adding interactivity, and styling elements. Students will apply these skills in a final project, where they create a website about themselves with guidance from the instructor.
Price: $360 / 12-week session

Web Development 1 & 2
The Web Development is a multi leveled curriculum, making more intense projects and focusing on back end development using today's frameworks and libraries, including but not limited too, Angular, NodeJS, and more.
Price: $280 / 8-week session
